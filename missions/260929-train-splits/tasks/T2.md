# T2 Luau split system v1  (mission 260929-train-splits)
Goal: Studio-ready Luau that (a) restructures Joel's train into four half-carriages and cuts the 10 crossing pieces per carriage exactly along the designed jagged tear, and (b) at runtime tears a carriage in half on command: explosion cue, lost part topples and falls behind with the terrain. Nothing can run in Studio here: prove the logic with Lune. Stage: v1 for the security gate and owner Studio test.

M = /home/user/claude/missions/260929-train-splits. Read only: refs/train.facts.md; mission.md (Requirements, Decisions A1-A9, Spec, Acceptance); src/kit/break_spec.json and the docstring of src/kit/break_spec.py (cells, cutter rules, motion, topple, events, lost rule); src/analysis/groups.json (957 part bboxes from the export, for the synthetic train). Lune 0.10.5 is at ~/.cargo/bin/lune (@lune/roblox has Instance/CFrame/Vector3/attributes/Clone/serializeModel; no engine methods like PivotTo, GetBoundingBox, SubtractAsync, TweenService: shim what you need in tests, keep production code free of test hacks).
Facts that matter: Studio names are generic ("Part", "Union"...), so find things by geometry, never by the export's numbered names. Each carriage has a roof UnionOperation of size ~(19.48, 3.59, 62.34) in some axis order: that is the carriage reference (B = roof centre + rear*3.31 + up*(-12.258); rear = toward the train's rear; front = lower coordinate along the long axis by default, config FRONT_AT = "min"|"max"). Fallback if no roof union: cluster parts along the long axis. The train never moves; the world scrolls (+Z = toward the rear in the export).

Write in src/luau/ (plain .lua files, Luau syntax, task.* not wait/spawn, no loadstring, no asset requires):
1. RR_BreakChecker.lua (command bar, read-only): select the train Model; prints carriages, each break frame, every BasePart whose bbox crosses the tear (cells + 0.1 margin) with class, full path, size; flags parts that sit inside the jagged band without crossing; exit summary. Generic fallback for other trains: a single plane at a configurable offset.
2. RR_TrainSplit_Setup.lua (command bar): DRY_RUN = true at the top prints the plan (counts per half, crossers and how each will be cut, anything unexpected). DRY_RUN = false: ChangeHistoryService waypoint; clone the train into ServerStorage.RR_Backups (named with a timestamp); create Train/Carriage1/{FrontHalf,RearHalf}, Train/Carriage2/{FrontHalf,RearHalf} Models, each with an invisible anchored non-colliding 1x1x1 Root (PrimaryPart) at the half's centre; move every other part into its half by bbox centre vs its carriage's break (gangway union between the carriages -> Carriage1.RearHalf), mirroring sub-containers (same class/name) so the builder's hierarchy survives; cut every crosser: axis-aligned Block Parts sliced into per-cell boxes (exact), everything else part:SubtractAsync(cutterParts) with pcall (front piece = minus REAR cutter boxes, rear piece = minus FRONT cutter boxes; cutter boxes built from the cells in the B frame, parented to a temporary folder, destroyed after), copying Name, Color, Material, MaterialVariant, Transparency, Reflectance, UsePartColor, CastShadow, CanCollide/CanQuery/CanTouch, CollisionGroup, Anchored, Massless, CollisionFidelity/RenderFidelity where settable, attributes and CollectionService tags, and re-homing children (attachments/lights/emitters by world position; others reported); report joints/constraints that referenced a cut original. Originals are moved into the backup folder, never destroyed. Train/RR_Breaks/Break1..2 (Configuration: attributes Carriage, BreakCFrame, Intact=true, Version="2.0.0"; ObjectValues KeptHalf, LostHalf). Refuse to run twice (RR_Breaks exists) and refuse unless exactly 2 carriages are found (print why). A final report: parts per half, crossers cut, CSG failures (with what to do).
3. TrainSplitShared.lua (ModuleScript for ReplicatedStorage): pure, deterministic math used by server and client: drift(t, V, a, recoil), topple(t, body) -> roll/yaw/sink, bodyCFrame(baseRootCF, breakCF, pivotSide, t, params), lostHalves(breakState, k), eventsTimeline. Numbers from break_spec (embed them in TrainSplitConfig, not here).
4. TrainSplitConfig.lua (ModuleScript, ReplicatedStorage): all tunables (speed default 35 and the train attribute name "Speed", brake 12, recoil, topple bodies, side "random"|"left"|"right", despawn 700 studs / 30 s, shake strengths, reduce-motion attribute name, FX preset names and anchors, Sounds = { metal_tear = {SoundId = "", Volume = ..., Is3D = ...}, split_explosion, split_glass, debris_rain, topple_crash, wreck_scrape }) with comments saying where each id comes from.
5. TrainSplit.lua (ModuleScript, ServerScriptService): GetBreaks(train), IsIntact(train, k), SplitAt(train, k, opts) -> {bodies, riders} (server only; idempotent; lost set per break_spec lost rule and current state, e.g. 2 then 1 loses only C1.Rear + C2.Front), moves the lost halves into workspace.RR_Wrecks as bodies (C2 halves together if both lost at once), welds each body's anchored parts to the body root and unanchors them (root stays anchored), drives root.CFrame + root.AssemblyLinearVelocity each Heartbeat from TrainSplitShared (riders are carried), optional opts.terrain Instance (hand the wreck to the owner's terrain mover once it moves at terrain speed), despawns; creates ReplicatedStorage.RR_TrainSplitFX (RemoteEvent, server -> clients only, never OnServerEvent) and FireAllClients(payload with k, t0 = workspace:GetServerTimeNow(), breakCF, bodies, params, seed); BindableEvents Snapped, Despawned.
6. TrainSplitClient.lua (LocalScript, StarterPlayerScripts): on the event, plays the break_spec events timeline: fx through ReplicatedStorage.RR_VFX if it exists (VFX.burst(anchor, name) / VFX.attach) else a small built-in fallback emitter set from TrainSplitConfig; sounds from TrainSplitConfig.Sounds (skip empty ids); camera shake (distance-scaled, off when the reduce-motion attribute is true); smooths each wreck root every RenderStepped with TrainSplitShared (client-local CFrame, welded parts follow).
7. TrainSplitDemo.server.lua: Studio test only: set attribute RR_TestBreak = 1 or 2 on the train -> SplitAt.
8. src/luau/tests/: a Lune harness that builds the synthetic train from groups.json (Parts; Union* -> UnionOperation; Part269/Part409 are axis-aligned Blocks), shims game services and SubtractAsync (return a UnionOperation whose bbox is the part bbox clipped by the cutter cells), runs the checker and the setup (DRY_RUN and apply) through @lune/luau load with a custom environment, and asserts: 20 crossers (10 per carriage, matching break_spec expected lists), 2 blocks sliced per cell, every other part in the right half (report counts), gangway in Carriage1.RearHalf, backups + break records present; repeat with the train moved (+500, +20, -300) and rotated 90 deg and 180 deg about Y; runtime pure functions: drift values at t = 0, 0.2, 1, 2.917, 5 and topple angles at key times; lost sets for 1, 2, 1-then-2, 2-then-1. One command runs all: lune run tests/run_tests.luau (print PASS/FAIL per check, exit code != 0 on failure).
